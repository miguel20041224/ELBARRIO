4. LECCIÓN IMPORTANTE — CÓMO CALIBRAR
================================================================================

La calibración de umbrales del commit edc19f1 ESTABA MAL y se corrigió en
cba457f. Vale la pena entender por qué, porque es un error fácil de repetir.

Se midió con un arnés que inflaba reputación y minutos a mano. Ese arnés daba
un techo de rating de 7,61 para un delantero de élite. Pero en carreras reales,
pasadas por el service completo, el techo es 7,16. Resultado: los umbrales que
se "corrigieron" en edc19f1 seguían siendo inalcanzables en juego real.

REGLA: calibrar SIEMPRE contra carreras corridas por el service completo
(create_career / play_match / advance_season / resolve_event / spin_roulette),
nunca contra un loop hecho a mano que setea el estado del jugador de prepo.

Distribuciones reales medidas (~430 temporadas, club grande, >=15 PJ):

    escala      mediana   p85    p95    techo
    ataque       6,71     6,93   7,05   7,16
    defensa      6,25     6,37   6,45   6,63
    arquero      6,11     6,23   6,31   6,39

    Vallas invictas (CB/GK):  mediana 6 · p85 9 · p95 11 · techo 15
    G+A (ST):                 mediana 16 · p85 24 · p95 28 · techo 35
    Temporadas con título en un club grande: ~30 %

Segunda regla que salió de acá: si un premio "no se gana nunca", antes de tocar
el umbral hay que preguntarse si el motor mide lo que el premio pide. Dos veces
en esta sesión la causa no era el umbral sino que el dato no existía:

    · El rating no miraba los atributos del jugador. Un pibe de 55 y un crack
      de 86 arrancaban ambos en 6,2.
    · Una valla invicta no le sumaba nada al rating de un central.

6. CÓMO LEVANTAR EL ENTORNO
================================================================================

Backend:

    cd backend
    poetry install
    poetry run alembic upgrade head
    poetry run uvicorn app.main:app --reload --app-dir src
    poetry run pytest -q

Frontend:

    cd frontend
    npm install
    npm run dev

    El build de producción EXIGE VITE_API_URL definida; es a propósito, para
    que un deploy mal configurado falle al construir y no en el navegador del
    usuario. Para un build local:

        VITE_API_URL="http://localhost:8000/api" npm run build
